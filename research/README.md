# Research

Ideas, inspiration and investigations for this repo. Domain or technical. See [ADR 0005](../docs/adr/0005-research-objects-before-specs.md).

**Nothing in here is implementable.** A research object reaches implementation only by passing the quality gates and becoming an epic or spec.

## Layout

One directory per object, `NNNN-<slug>/`, with `README.md`, `sources.md` and `discussion.md`.

## Lifecycle

```
seed → exploring → concluded → promoted | parked | rejected
```

Parked and rejected objects stay. The reason is part of the record.
