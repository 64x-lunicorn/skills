# Terms

The words this project uses with one fixed meaning, one paragraph each. Code, issues and Specs use the same word; a new term is added here when it gets a fixed meaning.

**Order**: a customer's line items priced together at checkout, from cart to receipt.

**Seam**: the public boundary where behaviour is observed without reaching inside, such as an exported interface, an endpoint or a command.

**Pricing**: the discount and tax math applied to an order's total between checkout and receipt.
