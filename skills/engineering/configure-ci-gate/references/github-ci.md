# GitHub CI templates

Read when generating `.github/workflows/ci.yml` and `.github/dependabot.yml`. Placeholders are `<<name>>`; `${{ }}` is GitHub Actions syntax and stays as it is. Pins verified 2026-09-14.

## Fill rules

- A placeholder is replaced by its value alone. Quotes written around a placeholder in a template stay; none are added. Inside double quotes, `\` and `"` in the value are escaped.
- A placeholder that resolves to nothing is removed together with its whole line.
- A generated file is the content of its fenced block below, ending with exactly one newline.
- `<<default_branch>>`: `default_branch` from the marker.
- `<<runs_on>>`: the runner of the stack in the runtime templates.
- `<<matrix_entries>>`: one entry per `ci.checks` item, in marker order, in exactly this shape and indentation:

  ```yaml
            - name: "<name>"
              run: "<run>"
              required: <true | false>
  ```

  A check with `secrets` gets a fourth line, the names in marker order, each followed by one space and the first preceded by one:

  ```yaml
              secrets: " <NAME1> <NAME2> "
  ```

- `<<check_secrets>>`: one line per distinct secret across all checks, sorted by name, in exactly this shape and indentation, or nothing when no check names a secret:

  ```yaml
            <NAME>: ${{ contains(matrix.secrets, ' <NAME> ') && secrets.<NAME> || '' }}
  ```

  The spaces around each name make `contains`, a substring test on a string, match whole names only, so a secret reaches only the checks that named it. A check that names none gets an empty value, and no `${{ }}` enters the `run` block.

- `<<setup_steps>>`: the stack's setup steps from the runtime templates, inserted as they are; their lines are already indented.
- `<<dependabot_stack>>`: the stack's Dependabot entry from the runtime templates, inserted as it is, or nothing when the stack has none.

## `.github/workflows/ci.yml`

````yaml
# The quality gate. It runs on every pull request into <<default_branch>> and
# ends in one job, "CI gate", which is the only check the branch ruleset
# requires.
#
# Generated by configure-ci-gate from .claude/64x-lunicorn.yml. Change the
# checks there and re-run setup; edits made here are reported as drift.
#
# Design notes:
#   * The checks run as one matrix generated from ci.checks, so adding a check
#     never touches branch protection.
#   * Least privilege: no token permissions by default, each job grants the
#     minimum it needs.
#   * Third-party actions are pinned to a commit SHA. Dependabot keeps them
#     current.
#   * A check with required: false is advisory: its failure never blocks.
name: CI

on:
  pull_request:
    branches: [<<default_branch>>]

permissions: {}

# A superseded push to a pull request has nothing left to prove.
concurrency:
  group: ci-${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  checks:
    name: ${{ matrix.name }}
    runs-on: <<runs_on>>
    permissions:
      contents: read
    continue-on-error: ${{ matrix.required == false }}
    strategy:
      fail-fast: false
      matrix:
        include:
<<matrix_entries>>
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          # checkout otherwise leaves the workflow token in .git/config,
          # readable by every later step in the job.
          persist-credentials: false

<<setup_steps>>

      - name: Run check
        env:
          CHECK_RUN: ${{ matrix.run }}
<<check_secrets>>
        run: bash -c "${CHECK_RUN}"

  workflows:
    name: Workflow lint
    runs-on: ubuntu-24.04
    permissions:
      contents: read
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          persist-credentials: false

      - name: actionlint
        env:
          ACTIONLINT_VERSION: 1.7.12
          ACTIONLINT_SHA256: 8aca8db96f1b94770f1b0d72b6dddcb1ebb8123cb3712530b08cc387b349a3d8
        run: |
          set -euo pipefail
          curl -sSfL -o actionlint.tar.gz \
            "https://github.com/rhysd/actionlint/releases/download/v${ACTIONLINT_VERSION}/actionlint_${ACTIONLINT_VERSION}_linux_amd64.tar.gz"
          echo "${ACTIONLINT_SHA256}  actionlint.tar.gz" | sha256sum -c -
          tar -xzf actionlint.tar.gz actionlint
          ./actionlint -color

      # zizmor audits the workflows and the Dependabot configuration: unpinned
      # actions, injectable ${{ }} interpolation in run blocks, over-broad
      # token permissions, dangerous triggers, missing update cooldowns.
      - name: zizmor
        env:
          ZIZMOR_VERSION: 1.30.1
        run: |
          set -euo pipefail
          pipx install "zizmor==${ZIZMOR_VERSION}"
          zizmor --persona=regular --min-severity=low .github

  secrets:
    name: Secret scan
    runs-on: ubuntu-24.04
    permissions:
      contents: read
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          persist-credentials: false
          # Full history: a credential committed and "removed" later is still
          # in the repository and still leaked.
          fetch-depth: 0

      - name: gitleaks
        env:
          GITLEAKS_VERSION: 8.30.1
          GITLEAKS_SHA256: 551f6fc83ea457d62a0d98237cbad105af8d557003051f41f3e7ca7b3f2470eb
        run: |
          set -euo pipefail
          curl -sSfL -o gitleaks.tar.gz \
            "https://github.com/gitleaks/gitleaks/releases/download/v${GITLEAKS_VERSION}/gitleaks_${GITLEAKS_VERSION}_linux_x64.tar.gz"
          echo "${GITLEAKS_SHA256}  gitleaks.tar.gz" | sha256sum -c -
          tar -xzf gitleaks.tar.gz gitleaks
          ./gitleaks git --no-banner --redact --exit-code 1 .

  # The one job the ruleset requires. Adding or renaming a job above never
  # means editing branch protection, and a skipped or cancelled job cannot
  # pass as green.
  gate:
    name: CI gate
    if: always()
    needs: [checks, workflows, secrets]
    runs-on: ubuntu-24.04
    permissions: {}
    steps:
      - name: Verify every job succeeded
        env:
          RESULTS: ${{ join(needs.*.result, ' ') }}
        run: |
          set -euo pipefail
          echo "job results: ${RESULTS}"
          for result in ${RESULTS}; do
            if [ "${result}" != "success" ]; then
              echo "::error::A required CI job did not succeed (${RESULTS})."
              exit 1
            fi
          done
          echo "All required CI jobs succeeded."
````

## `.github/dependabot.yml`

````yaml
# Dependency updates arrive as pull requests, through the same gate as
# everything else. Without the github-actions entry, the SHA pins in CI would
# quietly rot. The seven-day cooldown keeps a freshly published, possibly
# compromised release out until it has been around for a week.
version: 2

updates:
<<dependabot_stack>>
  - package-ecosystem: github-actions
    directory: /
    schedule:
      interval: weekly
      day: monday
      time: "06:00"
      timezone: Europe/Berlin
    open-pull-requests-limit: 5
    cooldown:
      default-days: 7
    labels:
      - dependencies
    groups:
      actions:
        patterns:
          - "*"
````
