Write the subject line in imperative mood.

See [format](references/format.md#subject) and [the spec](https://www.conventionalcommits.org).
Jump to [rules](#rules).

```markdown
[not real](does-not-exist.md)
```

## Rules

Inline code like `[also not real](missing.md)` is not a reference.
